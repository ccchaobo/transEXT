# 原文与译文排版对齐规范

更新日期：2026-10-13。

## 产品目标和参考实现

读者可以按原栏位、段落起点、图表和公式位置核对译文。文字正确、任务成功和排版正确必须分别验收。

[沉浸式翻译使用说明](https://immersivetranslate.com/zh-Hans/docs/usage/)区分普通 PDF、PDF Pro 和 BabelDOC 等路径；各模式并不采用相同的对齐策略。
[BabelDOC 段落识别](https://funstory-ai.github.io/BabelDOC/ImplementationDetails/ParagraphFinding/ParagraphFinding/)先重建语义段落并保留版面信息。
[BabelDOC 排版说明](https://funstory-ai.github.io/BabelDOC/ImplementationDetails/Typesetting/Typesetting/)介绍原段落框内排版、换行、行距和字号适配，以及避开其他段落和图像后利用空白。该文档自身声明可能存在不准确之处，本项目借鉴其原则，以实际浏览器渲染和真实样本文献核验效果。

完整 PDF 重排引擎适合高保真译文文件导出，需要额外模型、字体、部署和兼容性工作。本次采用浏览器固定页框排版，保留原件和现有接口，没有接入 BabelDOC 引擎，不声明具备相同能力。

## 解析约束

1. 原生竖排边注单独保存、原样显示，不能阻塞水平正文的栏沟检测。
2. 同栏连续文字才可形成段落；同栏内的间距或字号边界不能用小写开头规则重新合并。
3. 原生文本块编号只能作为行距判断的辅助证据，不能覆盖分栏、水平重叠和字号变化。
4. 段落在页边界保存为独立片段，避免续文不出现在下一页、整段译文挤入起始页。行字号取主要文字字体，上下标不独立决定段落边界。
5. 关键词保留逐项边界和原行位置，不与摘要混合，不重排成正文段落。
6. 正文基准字号优先根据连续正文统计，避免大量小字号表格单元格决定正文字号。
7. 数值、数学行、图内轴标签不能仅因数字开头或粗体进入目录；图表内文字从目录中过滤。

## 覆盖排版约束

### 列表与段落结构（本轮补充）

保存视觉行框与语义结构两层信息。原文分点编号、列表标记、续行、首行缩进、悬挂缩进和嵌套位移分别记录；不能把所有换行直接压平，也不能把每条视觉行当一个新段落。嵌套列表在普通卡片中保留相对栏位的缩进，在覆盖页框中只使用块内位移，防止重复缩进。

翻译输入为语义条目，提示版本为 `v2-structure`，明确保留编号、分点和前导缩进。返回的编号缺失会被记录为失败，不以单段译文冒充结构保留成功。普通视觉换行在条目内部合并，模型仍需保持全部句子。提示升级不能自动覆盖有效的人工修正。

存量记录通过现有原文与行框生成结构；译文编号存在并能逐项匹配时直接恢复展示，无需再次翻译。无法匹配则显示提示并保留原文字，不生成虚构的条目内容。两种覆盖视图、段落卡片、完整段落窗口和双语 Markdown 使用同一语义结构。格式显示修复不修改原件，也不重写历史修订。

### 目录识别（本轮补充）

优先使用 PDF 自带书签；能唯一匹配段落时定位块，否则只定位页，不猜一个段落锚点。没有自带书签时，候选必须有完整章节编号或明确章节名称，并结合正文类型、字号与字重过滤。短、加粗和大写本身不构成目录证据。

表格指标、图内标签、裸单词、公式、数值、列表条目、标题与文章元信息不能混入章节目录。附录必须有编号与明确标题，不把 ARTICLE INFO 的字母间隔误认为附录。层级由有效章节重新构建，不继承旧误识别产生的路径。编号和标题被分成两个块时，必须在同一行、相近字号和短横向间距内拼合，并联合检查两个块的图表归属。仅包含论文标题的单条 PDF 书签不能覆盖正文目录。读取时对存量目录直接筛选；新解析器版本为 `1.0.5`。

本轮以真实 BrLP 隔离副本验证目录与 21 页排版，现有文献库中的回收站状态保持不变；并以新导入的真实 CodecLM 文献验证流式答疑。证据见 [本轮验收](acceptance/2026-10-12/reader-structure-stream/README.md)。规则仍采用保守识别；特殊的未编号标题可能需要 PDF 自带书签或后续人工目录编辑。

两种覆盖视图使用相同的布局计算和字体适配逻辑。页框尺寸、长宽比、顶部基准一致；译文不能通过增加页高或插入每行横带来推移后续内容。

正文遵守原栏宽。短行和标题仅向安全的右侧空白扩展；下方空白必须在下个文字或图表之前截止。未翻译文字同样参与碰撞检测。遮盖只沿成功翻译的实际行框与安全译文框的交集，不遮盖图像、公式、表格和未知结果。图形边界附近的标题和图例保留原画面，已有译文显示在页后“图文区域译文”卡中。

译文从原段落顶部开始换行，浏览器实测实际字形的宽高。默认使用原字号；空间不足时调整行距并逐步缩小，最小字号为首选字号的 65%，屏幕最小值为 5px。页面缩小时原文也随页缩小；该下限不保证任意窗口都可舒适阅读。字号由用户放大后不再自动缩小。

仍放不下时保留段落内滚动和完整对照入口，不能截断译文、缩写内容、遮住后续段落或挤进关键词栏。段落和栏区对齐不表示每条中文行的基线与英文行一一相同。

2026-10-13 修正：正文含数学符号不构成整段排除理由。识别行框与相邻独立公式发生重叠时，从候选区域中扣除保护框，选择保留至少原栏宽 75% 的连续区域显示完整译文。剩余区域过薄或没有安全区域时，原画面保留，并在固定页框之后显示完整译文卡和“核对原文与译文”入口；不能无提示地丢弃已有译文。页框尺寸保持不变，“显示原文”同时隐藏这些补充译文。

独立公式仍使用原始页画面。正文中的数学符号使用已有译文所含字符，不声明具有原数学字体的字形保真能力；精细的行内公式占位与回填仍需要完整排版引擎。

## 存量修复

`scripts/repair_layout_revision.py` 生成新解析修订，保留历史修订和原件。原文完全一致且来源可唯一确定的译文可以迁移；重复文字不强行匹配，旧标注明确标记需要重新定位，未知结果保留未知状态。

修复前保存 SQLite 一致性备份；队列空闲、暂停后台 worker 时执行。脚本不调用翻译服务，变化的段落由后续翻译任务补译。首次排版修复为 `1.0.4`，新文件解析采用 `1.0.5`；本轮列表与目录显示修复不强制重解析存量文献。

## 验收门槛

- 使用用户反馈的《磁共振成像-有代码.pdf》，不能仅以合成单栏样例验收。
- 首页关键词与完整摘要不混合；关键词逐行，摘要保持右栏。
- 全部 21 页检查页框尺寸与起点、译文框宽高、文字溢出、段落碰撞和图表保护区域。
- 桌面等效 110% 缩放、1440px 窗口、窄窗口和打开 AI 助手后重新检查。
- 保存首页、双栏正文、公式页、图表页和附录截图，逐张目视核对；测量和截图共同构成证据。
- 核对全文翻译状态、目录、原文切换、完整段落入口和原始文件指纹。
- 覆盖完整性必须独立于几何检查：从真实 API 中的成功译文生成预期集合，逐段核对左右对照、译文覆盖、原文＋覆盖译文的完整中文。任何既没有覆盖框也没有补充译文卡的正文都判失败，不能只检查已生成的框。
- CodecLM 第 5 页“While Self-Rubrics…”必须直接显示中文；全篇 18 页检查已有译文覆盖、逐字完整性、框碰撞、图表及公式保护，并检查薄框替代卡和原文切换。证据见 [覆盖完整性验收](acceptance/2026-10-13/overlay-coverage/README.md)。

真实样本记录见 `docs/acceptance/2026-10-12/layout-alignment/`。一个样本通过不能证明任意 PDF、扫描件或其他语言均可保持同版式。
