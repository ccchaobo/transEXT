# 前端视觉与交互规范

2026-10-13 更新。目标是让文献管理、对照阅读和 AI 问答形成清晰、连贯的科研工作区。参考现代对话工作区的布局，使用轻玻璃、柔和阴影和低饱和紫色强调操作，降低操作拥挤程度；论文保留白纸黑字。

## 技术边界

沿用原生 ES 模块和 CSS，无新增 npm、CDN 字体或组件库。共用菜单集中在 `apps/web/js/ui.js`，视觉令牌在 `apps/web/ui.css`，文献库布局在 `apps/web/library.css`。保留路由、控件 ID、接口及阅读状态。

框架与组件库可提供更丰富的生态，但需要迁移 DOM 更新、构建链和已有验收，开发与升级成本较高。当前主要是外观和操作入口优化，共用小组件即可；复杂编辑、多层菜单或多人状态增长后应重新评估框架。

文献数据模型、翻译收费触发条件、Zotero 权限、原件存储及解析规则未调整。新增浏览器偏好为 `localStorage.rr.appearance`，取值 `light`、`dark`、`system`。用户随后明确要求助手统一使用完整文献：本轮同时替换旧取文规则，移除范围控件；相关合同见 [AI 阅读](ai-reading.md)。

## 视觉规范

- 浅色以雾白、白色表面和紫色强调组成；深色使用石墨灰和较浅的紫色。统一通过令牌配置状态、背景和文本颜色。
- 导航、工具栏和菜单使用半透明表面，弹层增加背景模糊及细边框。没有模糊支持时仍有可读底色。
- 标签圆角 6–8px，控件 10–12px，卡片和菜单 14–16px，对话框 20px。间距基于 4px 倍数。
- 图标为本地 SVG，辅助图标 `aria-hidden`，按钮保留中文名称；装饰箭头不改变 AI 预设按钮的可访问名称。
- 原文图片、遮罩和译文页框为不透明白底，内部颜色不继承深色外观；不在原件页框增加会改变锚点的内边距或变形。
- 详情保存操作放在有背景的底部操作栏，避免单个按钮悬浮在字段上。

## 菜单

分类每行右侧“⋯”与右键提供重命名、删除入口，不必先切换分类。删除分类只移除关系，保留文献、译文、原件和标注，需要确认。

文献行右侧“⋯”与右键提供阅读、原件、收藏、分类、标签、已读和回收站；回收站条目显示恢复及永久删除。操作只作用于目标条目，不隐式改变其他勾选项。永久删除保留明确确认和后端确认字段。

一次只开一个菜单。使用 Popover 顶层避免滚动容器裁切，并在视口边缘翻转、限制位置；没有 Popover 支持时使用固定定位。滚动触发器所在的区域、改变窗口尺寸、切换路由或点击外部会关闭。打开菜单时触发的滚动不会立即将它关闭。文献库刷新仅清理自身菜单，不会误关闭顶部外观菜单。

遵循 [W3C 菜单按钮模式](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/)：声明 `aria-haspopup`、`aria-expanded` 和菜单角色，Enter/Space 打开，方向键及 Home/End 移动焦点，Escape 关闭并恢复触发器焦点，Tab 退出。Shift+F10 或菜单键可打开行菜单；触控有可见按钮入口。危险项分组并用红色，确认框初始焦点为取消。

分类删除和永久删除使用应用内确认框。未保存修改的离开检查沿用浏览器确认，保留原来的同步路由保护，不为样式调整重写编辑状态机。

## 下拉控件与外观

语言、排序、阅读视图、字号、提问方式、思考强度和表单继续用原生 `select`，保留 `.value`、`change`、表单语义及禁用状态。支持 `appearance: base-select` 的浏览器显示圆角弹层、勾选标记与展开动效；其他浏览器保留经过样式统一的原生控件。不维护隐藏 select 与自定义控件两套状态。参见 [MDN 原生可定制选择器](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select)。

顶部可选择浅色、深色或跟随系统，刷新后保留。跟随系统实时响应系统外观变化；主题不影响原件和导出内容。

文献助手保留单一全文接入卡，将新对话、回答依据和强度放入设置菜单。底部输入框整合提问方式、模型名称、发送和停止；划词只作为关注内容，不限制全文。回答支持 Markdown、复制、可折叠来源和公开依据摘要，流式更新不强制把正在阅读旧内容的用户拉到底部。离线 Markdown 解析器版本和渲染边界见 AI 阅读规范；未新增网页运行时外部依赖。

## 动效与窄屏

新增交互使用 120–220ms 的颜色、透明度及小幅位移动效，不给论文正文添加入场位移。启用“减少动态效果”后关闭新增菜单、面板及控件动画，操作不依赖动画完成。

桌面文献库保持导航、列表、详情三栏；中等宽度详情移到列表下方；窄屏分类可滚动，表格仅在自身容器内横向滚动，菜单保持在视口内。阅读器保留窄屏目录入口及上下布局，不允许整页横向溢出。

## 验收

自编 PDF、示例书目及隔离数据库用于验收，不向真实库写测试记录，不调用外部翻译或付费模型。检查菜单键盘与焦点恢复、右键目标、重命名、删除取消/确认、文献操作、下拉 change、主题持久化及系统变化、减少动态效果、1440/1024/768/390px 布局、白纸黑字与页框比例。

继续执行导入、编辑、搜索、批量操作、回收站恢复、分页及 AI 预设上下文回归。Docker 使用独立项目与数据卷核对镜像内静态资源；一键部署包和本机镜像包含最终源码。证据见 [本轮验收](acceptance/2026-10-13/workspace-ui/README.md)。
