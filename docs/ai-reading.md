# 原文对照与 AI 阅读助手

更新日期：2026-10-13。

## 阅读与排版

“原文＋覆盖译文”和“译文覆盖”共用固定页框与字体适配逻辑。两侧页框高度、起点、原栏宽一致，不以拉长页面推动后续图像或段落。右侧保留图表与公式原件画面；特别长的译文在段落内滚动，也可双击或使用“查看本段”读取完整对照。详见 [排版规范](layout-alignment.md)。

译文保留原有的列表编号、分点、首行缩进、悬挂缩进和可识别的嵌套缩进。普通视觉换行在同一条目内合并，不把每行误认作一个新段落。存量译文只在原编号仍存在且能按顺序匹配时重建分点；缺失编号会提示，不猜测缺失的译文。源文字行框、原件、标注和解析修订不因显示修复而改变。

## 目录

优先使用有效的 PDF 自带书签；只有一个论文标题的书签时回退到正文章节。编号与标题分块时按同一行、字号和间距拼合。图内标签、表格指标和正文词语经过语义与区域筛选，不凭短、粗体或大写进入目录。新导入的医学扩散论文和 CodecLM 的正文及附录标题均已核对。

## 文献聊天

每次提问统一提供当前活动解析修订的完整文献文本，包含标题、作者、单位、摘要、章节、正文、列表、公式文字、图注、表格文字与结构、参考文献、页眉、页脚和页码等全部可读信息。按原阅读顺序编号为 `[S1]` 等来源，不按问题关键词、当前页或选区删减，不再限制八个来源或截断长段落。

界面采用文献接入卡、可滚动对话区和底部输入框；参考 [Claude 官方入门界面介绍](https://academy.claude.com/tutorials/getting-started-with-claude) 中的文件接入、对话和独立内容区域，把低频设置收进菜单，保持主要输入区简洁。本模块是文献对话界面，没有新增可以执行文件或系统操作的 agent 权限。

1. 点击“AI 阅读助手”，输入问题后按 Enter 或点击发送；Shift+Enter 换行。中文输入法组字期间的 Enter 不触发发送。
2. 三个预设只填写问题，清除旧关注内容，不自动请求服务；发送时仍提供全文。
3. 点击段落或划词可添加“关注内容”，术语、公式或普通问题都同时提供全文。关注点不是取文范围。旧客户端传入 `context_scope=selection/auto/document` 也统一使用全文。
4. “对话选项”提供新对话和对话设置。“回答依据”控制仅依据文献还是允许明确标注的通用补充；“思考强度”仍由服务支持决定，都不改变全文输入。
5. 答案流式出现，显示连接、思考、整理依据和输出阶段；“停止”或关闭面板停止接收，保留已有回答。不会自动重试，以免重复计费。
6. 答案显示 Markdown 标题、强调、嵌套列表、表格和代码，支持复制原回答及行内来源按钮。来源默认折叠；大量来源分批展示，但这不减少发送给模型的文献内容。
7. 阅读历史回答时不被每个流式片段拖回底部，可点“最新回答”回到新内容。

聊天仅保存在本次页面会话，同一文献重开面板可见，最多 30 个问题；发给模型的对话历史仍为最近 4 对完整问答，每条历史消息最多 6000 字符。该历史限制不截断文献全文。“新对话”清空当前聊天及关注点，保留全文文献接入与回答设置。

## 全文合同与长度处理

`GET /documents/{id}/assistant/context` 只返回文献接入状态：`strategy=full_document`、`complete=true`、`excerpts=false`、全部文字块数、字符数、页覆盖和类型统计。前端在发送前核对实时全文合同；旧后端仍返回局部资料时不发送模型请求，不把八段标成全文。流式 meta 与 done 也携带真实完整性信息。

所有有文字或结构化表格的块都进入模型输入，包括不可翻译的文字块。仅有标题的解析结果可用于标题或书目信息提问，状态会如实报告正文为零；完全没有可读文字时在请求模型前返回 `no_context`。原件像素不是文本输入：只有图片、无法提取的公式或图内细节不能宣称已经看到了，提供已有图注、文字和表格结构。

单篇全文超过 200 万字符时，返回 `full_document_too_large` 并在本机拒绝整个请求，保护资源，不裁成局部内容。AI 服务明确拒绝上下文容量时返回 `assistant_context_limit`，提示更换更长上下文模型，不改发节选、不自动重试。模型可处理长度以服务为准；[Ollama 官方说明](https://docs.ollama.com/context-length) 解释了上下文容量及本地/云端设置差异，不能把本机字符数当作精确 token 容量。

每次请求重复提供全文，复用已配置的翻译服务，可能计费。问题上限 2000 字符，关注文字 6000 字符，输出预算 8192 tokens；超时和中断结果不明时保留已有内容。全文接入状态读取、打开面板、点击预设及调整外观不会调用付费模型。

## 回答显示与依据

离线打包 `markdown-it` 15.0.2（MIT），来源及完整性记录在 `apps/web/vendor/markdown-it/manifest.json`，无需运行时 CDN。关闭原始 HTML；外部图片只显示文字说明，不自动加载；只允许 HTTP(S) 链接，打开时隔离 opener。来源按钮由 DOM API 创建，不执行模型生成的脚本。

模型内部逐步思维链不发送给浏览器、不保存。可折叠“回答依据摘要”是模型正式输出中的公开说明，不等同于内部推理。阶段、耗时和请求强度仍须区分，不能仅凭耗时推断真实思考程度。

回答以本次完整来源为准，不沿用历史“只有标题”的判断；已有正文时不能声称只拿到了目录。缺少的具体图像、数值或实验细节必须说明，不得编造来源编号、页码或参考文献。

## 验收边界

定向与全套后端回归、前端渲染测试、受控浏览器请求逐字核对完整输入，并覆盖标题选中、三个预设、设置、停止、复制、Markdown、来源折叠、旧后端拒绝及窄屏。受控服务不等同于真实模型回答质量；验收不调用付费模型、不修改用户论文。记录见 [全文文献聊天验收](acceptance/2026-10-13/assistant-full-document/README.md) 与 [整体 UI 验收](acceptance/2026-10-13/workspace-ui/README.md)。
