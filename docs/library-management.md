# 文献管理规范

2026-10-12 更新。用户目标为添加、删除、整理和检索文献，并与现有 Zotero 联动。用户已选择复用 Zotero 的书目与同步能力，已同意同步设计文档。最新验收范围为 Zotero 导入与联动，Word 实际插入不作为本次完成条件。

## 信息架构与主要流程

文献库采用分类导航、文献表格、详情编辑三栏。导入支持文件选择、拖放和多文件；批量导入后仍停留在文献库。双击条目或“打开阅读”进入原件与译文对照。

2026-10-13 优化视觉和入口：分类每行的右侧“⋯”或右键菜单提供重命名与删除；文献行提供更多操作及右键菜单。新增浅色、深色和跟随系统外观，统一下拉控件及弹窗；详情保存使用底部操作栏。菜单的键盘操作、删除确认和窄屏规范见 [前端设计](ui-design.md)。

导航提供全部文献、未分类、收藏、未读、阅读中、已读、回收站、分类和标签。搜索覆盖全库的标题、文件名、作者、来源、DOI 和标签，分类与标签可组合筛选；按最近添加、标题、年份排序。每页默认 100 条，可加载更多。

详情可编辑标题、作者、年份、期刊或来源、DOI、来源链接、文献类型、摘要、标签、笔记和阅读状态。分类采用多对多归属，一篇文献可属于多个分类。删除分类或从分类移除文献，只取消归属，不删除文献。改动未保存时离开详情需要确认。

批量操作包括收藏、阅读状态、添加或移除标签、添加或移除分类、移入回收站、恢复和永久删除。交互在操作提交期间锁定，防止勾选状态和返回结果错配。

## 数据与删除语义

- 原件保存在不可变的来源路径，书目信息位于 `Document.extra.bibliography`，标签位于 `DocumentLabel`。
- `LibraryCollection` 与 `CollectionDocument` 管理分类及多对多归属。
- `Document.deleted_at` 标记回收站状态。回收站中的文献不出现在普通阅读列表，恢复保留原件、解析修订、译文、标注和分类归属。
- 永久删除只允许已在回收站的文献，并需明确确认；运行中的任务会阻止永久删除。批量参数先整体验证，防止部分执行。
- 相同文件指纹复用同一文献。重新导入回收站文件会恢复原记录；尚未解析的记录恢复时重新安排解析。
- 本地回收站和永久删除不会删除 Zotero 中的条目或附件。

## Zotero 联动

“Zotero 文献库”读取和检索本机目录、导出引用数据、预览网页或 DOI 书目、复制选中的 PDF 进入阅读器。没有 PDF 的书目仍可在 Zotero 目录中存在。

本地详情“Zotero 关联与写回”可关联已有书目，或将本地书目信息新增到明确选择的 Zotero 文献库。PDF 附件复制为可选项。已有关联会锁定原文献库，防止误写到另一库。写回前显示书目信息差异，冲突时需选择采用 Zotero 版本或将本地修改写回。详见 [Zotero 集成规范](zotero-integration.md)。

本地分类、笔记、阅读状态、译文和标注是阅读器自己的数据；当前不会自动写成 Zotero 分类或 Zotero 笔记。Zotero 内部的集合、引用样式、账户和云端同步仍由 Zotero 管理。

## 验收标准与证据

1. 中文作者、标签和 DOI 检索能查全库，超过 100 条时可继续加载。
2. 分类移除不丢文献；回收站恢复不丢原件、译文、标注及修订；永久删除有确认门槛。
3. 批量操作与状态筛选一致，原件指纹不因元数据编辑而变化。
4. 桌面、平板和 390px 窄屏没有整页横向溢出，导航、表格与详情均可访问。
5. 进入阅读后返回文献库正常，真实 PDF 排版不退化。

隔离数据库集成测试：`tests/integration/test_library.py`；真实 Chrome 脚本：`scripts/verify_library_browser.py`。报告：[library-management/report.json](acceptance/2026-10-12/library-management/report.json)。这些测试使用隔离文献，不修改用户原有的 7 篇文献。
