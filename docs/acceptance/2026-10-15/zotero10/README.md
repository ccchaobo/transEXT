# Zotero 10 升级兼容验收

2026-10-15。故障来自组件 0.1.1 的 `9.0.*` 兼容上限、容器内回环地址以及 Docker 数据卷未继承原本机配对。组件升级为 0.2.0，Docker 使用同机宿主机目标并复用原授权。没有关闭全局安全检查或发布 Zotero 端口。

- 真实 Zotero 10.0.6 加载组件，`authorized/can_write=true`。
- 目录读取 130 个记录、59 篇书目和 33 个 PDF 附件；Chrome 搜索、RIS 下载、1440/768/390px 布局通过，共 8 项。
- 读取一份 17 页、668275 字节的真实已下载 PDF，跨系统传输后 MD5 与来源一致。未新增阅读器文献，未调用付费模型，未修改、合并或删除 Zotero 条目。
- 767 项后端、38 项 Node 前端测试通过，其中 10 项组件测试验证版本合同、鉴权、冲突、重放、PDF 上传完整性、复用和临时文件清理。隔离测试不代表真实用户库的写入验收。
- 更新前原数据卷一致性备份已完成；更新后仍是 5 篇文献、7 个已完成后台任务。API、worker、GROBID 均健康。

见 [真实检查](live-report.json)、[浏览器检查](browser-report.json)。真实书目截图与 RIS 保存在忽略的 `var/zotero-browser/`，不提交用户文献内容。

Docker 数据卷独立配对和升级步骤见 [联动规范](../../../zotero-integration.md)。本次没有验收云同步、Word、远程服务器或 Linux Docker 桌面回环转发。镜像仅保存在本机 Docker，不代表已发布到镜像仓库。
