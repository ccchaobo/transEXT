# 整体工作区 UI 验收

用户要求参考现代对话工作区及轻玻璃视觉，统一优化前端；分类与文献操作通过右侧“⋯”和右键菜单进入。用户已批准同步文档、提交 Git 与保存 Docker 内容，随后补充要求文献助手统一接入完整文章。

本轮包含导航、列表、详情保存栏、阅读工具栏、原生下拉弹层、菜单、删除确认、浅/深色与系统外观、文献聊天。论文白底画布与原锚点比例保持一致，新增效果不覆盖正文或图片。

验收使用隔离数据库、自编 PDF 与书目信息，没有改动用户文献，也没有调用付费模型。

- 前端 34 项测试通过：既有阅读器与连接组件回归，新增 Markdown 结构、HTML/图片及链接处理测试。
- 后端全套 764 项通过；OpenAPI 64 schema、48 path 校验通过，包含依赖缓存版本保护回归。
- Chrome 工作区 25 项浏览器检查通过：键盘与焦点、右键、重命名、删除取消/确认、条目操作、下拉排序、外观及持久化、视口边界、Popover 回退、白纸黑字、减少动态效果、原件/修订保留与无模型请求。见 [记录](report.json)。
- Edge 验证不支持新选择器时的原生控件回退，同样 25 项通过，见 [记录](edge-report.json)。
- 原文献库 25 项浏览器回归通过，涵盖导入、编辑、搜索、批量整理、回收站恢复及超过 100 条分页，见 [记录](library-regression/report.json)。
- 完整文献聊天的请求、停止、复制、设置与安全显示另见 [专项验收](../assistant-full-document/README.md)。

桌面浅色、分类菜单、原生下拉弹层、深色和窄屏截图位于本目录。最终聊天界面以专项验收截图为准。截图展示自编验收材料，不作为真实论文内容或真实模型概括质量证明。

设计选择、浏览器回退和适用范围见 [UI 规范](../../../ui-design.md)。Docker 与部署包核对记录在专项验收中；用户文献、密钥和备份不进入 Git 或部署源码 ZIP。
