# 覆盖视图译文完整性验收

2026-10-13，样本为用户反馈的真实 CodecLM 文献，第 5 页“While Self-Rubrics…”已有中文但覆盖视图保留英文。

根因是正文与下一行独立公式的字体框重叠，旧规则因此跳过整个段落；另一个规则直接排除含特定数学符号的正文。旧几何验收只检查已生成的译文框，未生成的框不会报错。

## 本次修正

- 不按正文中是否包含数学符号排除整段译文。
- 从译文候选框扣除图表、表格、独立公式的保护区域，再在可用连续区域中排完整中文。
- 无安全区域或剩余空间过薄时，在固定页框之后显示完整译文卡，并可打开完整原文与译文对照。
- 原文切换隐藏覆盖框和补充译文卡。原件、译文记录和人工修订保持不变，无重新翻译请求。

## 验证范围

运行 `E:\anaconda\python.exe scripts/verify_overlay_coverage.py`，Microsoft Edge 独立无界面浏览器，版本与详细测量见 [report.json](report.json)。验收请求中拦截所有写入及阅读状态保存，避免改变真实文献库或阅读位置。

真实 18 页，逐页核对左右对照、译文覆盖、原文＋覆盖译文。预期集合来自 API 中成功且有实际文本变化的可翻译内容，独立于覆盖算法的输出。共有 166 个需要展示的译文条目，三种模式逐字核对，没有漏显或内容截断；覆盖模式其中 150 个直接覆盖，16 个使用补充卡。图表与独立公式保护区域、译文框碰撞、过薄框、固定页框尺寸及原件 SHA-256 同时检查。

第 5 页反馈段落直接显示中文，两种覆盖模式均验证。1745px（1920px 显示器约 110% 缩放的 CSS 宽度）、1440px、1024px 均检查；100% 字号可放下该段，120% 字号采用段落内滚动保留完整译文。未对实际 Chrome 浏览器缩放设置进行操作，不能把等效视口测量称为原用户窗口的实时验收。
