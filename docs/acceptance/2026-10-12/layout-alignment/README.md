## 根因与修复

竖排 arXiv 标记阻塞分栏，导致关键词混进摘要；旧覆盖视图按行切割和展开，使页高与段落位置不一致。小字号表格单元格影响正文字号统计，上下标又影响行字号，进一步拆散段落。跨页合并块只出现在起始页，造成续页缺译和起始页过长。

修复为文本方向隔离、关键词逐项保存、连续正文字号统计、主要字体行字号、按页片段保存、固定页框和同一覆盖排版逻辑。文字区域的安全空白经过碰撞检查；图形边缘及邻近图例原样保留。原件和历史修订保留，旧标注显式标记需重新定位。

## 限制
